# ЛПХ Клубничный Смак

Статический сайт-визитка с интерактивной коллекцией сортов малины. Откройте `index.html` для локального просмотра. Сборка и установка не требуются.

Сорта, контакты и ссылки на источники находятся в `data.js`. У сорта можно указать `photo` с полями `src`, `alt` и `caption`. Сведения об авторах и лицензиях фотографий указаны в подвале сайта.

Публичный сайт размещён на GitHub Pages. Источник публикации — корень ветки `main` репозитория [Daryazz65/klubnichny-smak](https://github.com/Daryazz65/klubnichny-smak). Каждое обновление этой ветки запускает публикацию.
