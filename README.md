# ЛПХ Клубничный Смак

Статический сайт-визитка с каталогом плодовых деревьев, кустарников и травянистых ягодных культур. Откройте `index.html` для локального просмотра. Сборка и установка не требуются.

Сорта и контакты находятся в `data.js`.

Галерея открывается на `gallery.html`. Медиафайлы хранятся в `media`, кадрирование фотографий описано в `gallery.js`.

Публичный сайт размещён на GitHub Pages. Источник публикации — корень ветки `main` репозитория [Daryazz65/klubnichny-smak](https://github.com/Daryazz65/klubnichny-smak). Каждое обновление этой ветки запускает публикацию.
